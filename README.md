# 🌐 Comunidad Inteligente – Conjunto Residencial Azahar 🌼

## 📖 Descripción del proyecto
**Comunidad Inteligente** es un sistema web que busca optimizar la **gestión administrativa y logística** del Conjunto Residencial **Azahar**.  

El proyecto surge como respuesta a problemáticas comunes en la comunidad, tales como:  
- Pérdida y mala gestión de **paquetes**.  
- Ausencia de un **control de visitas** eficiente.  
- Falta de organización en las **solicitudes de áreas comunes**.  

Con este software se pretende garantizar mayor **seguridad**, **transparencia** y **orden** en los procesos del conjunto.

---

## 🎯 Propósito
- Crear un **sistema de seguridad y validaciones**.  
- Optimizar la **gestión de visitantes y residentes**.  
- Implementar un **control eficiente de paquetería**.  
- Mejorar el uso y la organización de las **áreas comunes**.  

---

## 🛠️ Tecnologías utilizadas

### 🔹 Backend
- **Node.js** – entorno de ejecución de JavaScript.  
- **Express.js** – framework para construir la API REST.  
- **JSON Web Token (JWT)** – autenticación y validación de usuarios.  
- **Middlewares personalizados** – para seguridad y control de accesos.  
- **MySQL** – base de datos relacional para almacenar la información.  

### 🔹 Frontend
- **React** – librería para la construcción de interfaces dinámicas.  
- **Vite.js** – herramienta de desarrollo rápida para proyectos con React.  
- **Bootstrap** – framework CSS para diseño responsivo y consistente.
